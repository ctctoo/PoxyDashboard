# 「总控台」应用测试用例文档

- 版本：针对当前 `main` 分支
- 日期：2026-08-19
- 适用对象：手工功能测试 / 验收测试
- 优先级定义：**P0**（阻塞发布）、**P1**（核心功能）、**P2**（次要功能）、**P3**（体验优化）

---

## 1. 测试概述

### 1.1 测试范围
本文档覆盖「总控台」桌面应用（Electron + Vue 3 + TypeScript）的全部用户可见功能模块：

| 模块 | 说明 |
| --- | --- |
| 启动台 | 服务/任务的增删改查、启动停止重启、排序、快捷操作 |
| 服务监控 | 概览卡片、端口提醒、服务表格、关注进程、后台应用、隐藏服务 |
| 数据库 | 数据库实例列表、启停、移除记录（独立侧边栏入口） |
| Docker | 容器列表、启停、端口打开（独立侧边栏入口） |
| AI Agent | agent 聚合视图、任务进程、启动/退出/重启 |
| 日志中心 | 应用日志列表、详情查看、筛选、滚动 |
| 设置中心 | 通知开关、主题切换、关于信息 |
| 命令面板 | 全局搜索执行动作（⌘K） |
| 进程生命周期 | 进程启动/停止/状态流转/异常处理 |

### 1.2 测试环境
- 系统：Windows 10/11（项目为 Windows 专属，PowerShell 采集进程）
- 运行时：Electron（主进程）+ 现代 Chromium
- 前置：Node.js 已安装；本机已安装部分 AI agent CLI（npm 全局）；有可运行的服务脚本

### 1.3 标注说明
- **[UI]** 需可视化核对
- **[数据]** 依赖实际运行环境
- **[耗时]** 依赖启动/停止真实进程，需等待轮询间隔
